# 🛒 Geekverso - Loja Virtual

## 📖 Sobre o projeto
Este é um projeto de loja virtual desenvolvido com HTML, CSS e JavaScript, com o objetivo de simular um e-commerce de produtos geeks.

O site apresenta produtos, preços e uma interface inspirada em lojas reais, permitindo praticar a construção de layouts mais completos e próximos do mercado.

---

## ✨ Funcionalidades
- Exibição de produtos
- Apresentação de preços
- Layout de loja virtual
- Interface organizada em seções
- Botões de ação (simulação de compra)

---

## 🎨 Layout
O projeto possui:
- Design inspirado em e-commerces reais
- Organização de produtos em cards
- Estrutura de loja (header, produtos, seções)
- Interface visual moderna

---

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

---

## 🎯 Aprendizados
Durante esse projeto, pratiquei:
- Estruturação de páginas mais complexas
- Organização de produtos em layout de loja
- Manipulação de elementos com JavaScript
- Pensamento de interface de e-commerce
- Criação de UI inspirada em projetos reais
